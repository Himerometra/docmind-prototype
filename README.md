# DocMind Prototype

DocMind 的工业文档处理 Web 前端原型。仓库使用原生 HTML、CSS 和 JavaScript，实现采购发票图片上传、结构化识别结果展示、任务记录与工作台等界面。识别和任务数据由独立的 MaaS 网关提供；本仓库不包含模型、后端服务或知识库。

## 当前功能

| 页面 | 状态 | 说明 |
| --- | --- | --- |
| 工作台 | 需后端 | 展示识别任务统计和最近任务。 |
| 图像识别 | 需后端与视觉模型 | 单张或批量上传采购发票图片，显示结构化结果。支持 JPG、PNG、WEBP，单文件上限 50 MB。 |
| 任务记录 | 需后端 | 按状态筛选、查看详情、重试失败任务，并将当前加载的记录导出为 CSV。 |
| 设置 | 前端可用 | 配置工作空间名称、API 地址和界面偏好；设置保存在当前浏览器的 `localStorage`。 |
| 知识问答、知识库 | 待接入 | 页面保留了入口，正式知识库尚未接入，问答输入处于禁用状态。 |

界面中的版本、节点和运行指标等装饰性文案仅用于原型展示；实际任务统计从后端获取。

## 本地预览

只查看界面时，需要 Python 3，并在仓库根目录运行：

```bash
python -m http.server 8765 --bind 127.0.0.1
```

然后访问 <http://127.0.0.1:8765/>。静态页面可以打开，但识别、任务列表和工作台动态数据需要后端。建议通过本地 HTTP 服务访问，而不是直接打开 `index.html`。

要运行完整流程，还需要启动与本前端接口兼容的 MaaS 网关及其视觉模型服务。可参考 [DocMind-WebApp](https://github.com/Himerometra/DocMind-WebApp) 的后端配置与启动说明。前端默认请求 `http://127.0.0.1:8000`；如后端地址不同，可在页面的「设置 → 模型服务」中修改并测试连接。前后端分开部署时，后端还需允许前端来源跨域访问。

## 前后端接口

前端当前使用以下接口：

| 方法与路径 | 用途 |
| --- | --- |
| `GET /health` | 检查网关连接。 |
| `POST /v1/extract` | 上传图片并获取识别结果。 |
| `GET /v1/dashboard` | 获取工作台统计。 |
| `GET /v1/tasks` | 查询任务列表。 |
| `GET /v1/tasks/{task_id}` | 查看任务详情。 |
| `POST /v1/tasks/{task_id}/retry` | 重试失败任务。 |

请求中使用了写在 `app.js` 里的演示用 Bearer Key `sk-demo-local`。它只适合本地原型联调；公开部署前应改用合适的身份验证方式，避免在浏览器代码中放置真实密钥。
